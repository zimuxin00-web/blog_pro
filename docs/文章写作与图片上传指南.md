# 怎么写文章、怎么传图（不用记格式，也不用命令行）

> 一句话：**以后发文章，你基本不用碰代码。** 有两条最省心的路，选你顺手的那条就行：
> 1. **直接在「Qexo 网页后台」写** —— 像以前用 Typecho 一样，浏览器里打字、拖图片、点发布。
> 2. **直接跟我（AI）说想写啥** —— 我帮你把文章和配图做好，你检查一下就能发。

---

## 方式一：用 Qexo 网页后台（最像你以前的 Typecho）

等你服务器部署好之后，浏览器打开后台地址（例如 `https://admin.maoniang.cloud`），登录即可。

**发一篇图文文章的完整流程**：

1. 点「写文章」/「新建」，会出现一个标题框 + 正文编辑区。
2. 顶部标题栏填标题（如《我的第一篇技术文》）。
3. 正文区直接打字，像用 Word 一样。想加小标题就点工具栏的「标题」，想做列表、加粗、代码框都有按钮。
4. **插图（关键，全程鼠标拖拽）**：直接把图片文件从电脑拖进正文，或点编辑器里的「图片」按钮选择本地图片，图片会自动上传并插入。所见即所得，能马上看到。
5. 右侧/设置里可以选**分类**（如「网络安全」「随笔」）和**标签**。
6. 点「保存」并「发布」。Qexo 会自动把它同步到 GitHub、触发服务器重建。
7. 过 1~2 分钟，打开 `maoniang.cloud` 首页就能看到新文章了。

> 想要封面图：在设置里传一张封面，或留空用默认封面。
> 想改/删：进后台找到那篇文章，改完保存即可；删了就点删除。

## 方式二：直接跟我说，我帮你写（你自己完全不用动手）

在聊天里直接讲你的想法就行，比如：

- 「写一篇讲我最近学的 Docker 的文章，帮我起个标题」
- 「把 OWASP 那篇讲得更通俗点，加个例子」
- 「写个菜谱文章，图我待会发你，帮我插到对应位置」

我会帮你：按博客需要的格式排版 → 处理好配图 → 甚至可以帮你直接发到后台/仓库。
你只需要**检查一遍文字对不对、想不想改**，改完说一声我就更新。

> 如果你的图已经存在手机/电脑里，直接发给我，我来安放和引用，你不用管它放哪、路径怎么写。

---

## 那“文件/Markdown/上传 GitHub”还跟我有关吗？

**几乎无关，但了解一点点没坏处：**

- 后台里的文章，本质是存在博客代码里的一些 `.md` 文本文件。**你不需要自己创建它们**——Qexo 或我会帮你做。
- “传到 GitHub、服务器重新生成”这些，也都由 Qexo + 服务器自动完成，**你不用手动上传 zip 或敲命令**。
- 万一你想直接看这些文件长啥样，它们在博客项目的 `source/_posts/` 文件夹里，用记事本打开能看到文字，但**正常你不需要碰它**。

## 常见问题速查

| 我想… | 怎么做 |
|---|---|
| 发一篇图文 | 方式一（后台写）或方式二（跟我说） |
| 插图 | 后台里直接拖图片进正文 / 发图给我 |
| 建新分类 / 加标签 | 后台文章设置里填；跟我说也行 |
| 改一篇文章 | 后台打开它改完保存 / 跟我说要改哪 |
| 删一篇文章 | 后台文章列表里点删除 |
| 换封面 | 后台文章设置里换一张图 |
| 前台多久能更新 | 一般 1~2 分钟内，最多几分钟 |

---

> 别担心“必须按格式写”——那是对**程序文件**的要求，不是对你的要求。Qexo 后台和你电脑/手机上的我，都会帮你把这些格式处理好。你只管想清楚写什么内容就行。
