## 开篇

站搭好了。这个博客跑在 **Hexo** 上，主题是 **[安知鱼](https://github.com/anzhiyu-c/hexo-theme-anzhiyu)**，生成出来的是一堆纯静态文件，直接丢给 Nginx 就能访问。

首页那个会动的背景，是一段循环播放的视频；如果你没放视频文件，它会自动降级成星屑粒子动画，不会开天窗。

## 以后怎么写文章

在本地博客目录里执行：

```bash
hexo new "文章标题"
```

这会在 `source/_posts/` 下生成一个 `.md` 文件和**一个同名的文件夹**——图片直接丢进那个文件夹就行。

文章里插图这样写：

```markdown
{% asset_img 我的图片.jpg 这是一张图片的说明 %}
```

然后本地预览：

```bash
hexo s
```

浏览器打开 `http://localhost:4000` 就能看到效果。满意了再执行 `./deploy/deploy.sh` 推到服务器。

## 关于"后台"

这是静态站，**不需要**数据库和后台。但也意味着没有网页版编辑器——写文章就是写 Markdown 文件。

如果你确实想要一个网页后台（在浏览器里写文章、拖图片上传），可以装 **Qexo** 或 **hexo-admin**，它们是在服务器上跑的一个小服务，帮你读写 Markdown 文件并自动触发构建。需要的话我再帮你接。
